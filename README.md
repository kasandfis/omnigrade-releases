# OmniGrade – Versionen und Updates

Hier liegen die fertigen, von Apple notarisierten Versionen von OmniGrade,
einer Notenverwaltung für Lehrpersonen, und die Dateien, mit denen sich die
App selbst aktualisiert. Der Programmcode liegt nicht hier.

- **Neu installieren:** unter «Releases» die neueste
  `OmniGrade_x.y.z_aarch64.dmg` laden (Mac mit Apple-Chip), öffnen und
  OmniGrade in den Ordner «Programme» ziehen.
- **Aktualisieren (ab Version 2.4.0):** OmniGrade sucht beim Start selbst
  nach einer neueren Version und fragt, bevor es etwas installiert.
  Abschaltbar unter Einstellungen › Profil › Updates.

**Datenschutz:** Die App ruft beim Start nur die Datei `latest.json` ab und
schickt dabei keine Daten mit. Klassen, Noten und Namen verlassen den
Computer nie. Jedes Update ist signiert; die App installiert nur Pakete mit
der passenden Signatur.
